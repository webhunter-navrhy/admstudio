# ADM REPRO studio – koncept
Tři nápady: (1) Tiskový arch – ořezové a pasovací značky kolem obsahu, CMYK body. (2) Pult s fronty – web jako objednávkový lístek. (3) Vazba – stránky jako hřbet knihy.
Vybrán 1: tiskárna, brand z loga (navy, azurová), fakta jen z admstudio.cz. Signature: CMYK kruhy v hero, které se při scrollu/načtení vysunou z registrace (CSS, bez knihoven).
Sekce: hero, závěrečné práce (35 000 / 7 Kč / 1 Kč / do 14:00), služby, jak objednat, reference (loga ze starého webu), kontakt + doba + formulář.
Písma Space Grotesk + Inter (self-host, latin-ext, háčky ověřit). Paleta #0c1f4a, #003399, #46b5df, #de7b85, papír #f7f6f2.
Zakázané vzory nepoužity. Skladba se liší od posledních webů (jednostránkový arch s ořezovými značkami).
